# 🛒 Superstore Interactive Dashboard

An interactive business intelligence dashboard built with **Tableau Public**, analyzing sales data from the Superstore dataset. This project delivers a dynamic and filterable view of sales, profit, and order performance across categories, regions, and time periods.

## 📌 Key Insights Covered

- 💰 **Sales & Profit Overview** — High-level KPIs across the entire dataset
- 🗂️ **Category & Sub-Category Analysis** — Best and worst performing product groups
- 🌏 **Region-wise Breakdown** — Sales and profit comparison across regions
- 📅 **Time-based Trends** — Monthly and yearly order and revenue patterns
- 🎛️ **Interactive Filters** — Dynamic filtering by category, region, and date

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Mahekyadav3/superstore-interactive-tableau-dashboard.git
   ```
2. Open `index.html` in any web browser
3. The Tableau dashboard will load automatically (requires internet connection)
